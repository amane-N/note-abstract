# プライバシーポリシー

**最終更新日: 2026-05-09**

## 1. 概要

note アブストラクト (以下「本拡張機能」) は、note.com の記事を論文のアブストラクト形式で要約・分析する Chrome 拡張機能です。本ポリシーは、本拡張機能がどのような情報を取り扱うかを説明します。

## 2. 収集する情報

**本拡張機能はユーザーの個人情報を収集しません。**

テレメトリ・アクセス解析・クラッシュレポートなど、いかなる分析機能も実装していません。

## 3. ローカルに保存する情報

以下の情報はユーザーの端末内 (`chrome.storage.local`) にのみ保存されます。外部サーバーには一切送信されません。

| 項目 | 説明 | 保存形式 |
|------|------|----------|
| Google AI Studio API キー | ユーザーが任意で設定する BYOK キー | XOR + Base64 難読化 |
| ライセンスコード | 有料層の有効化コード | プレーンテキスト |
| 記事要約履歴 | 有料層ユーザーの要約・予測・関連キーワード | JSON |
| 設定値 | 機能の有効/無効フラグ等 | JSON |

**注意**: API キーの難読化はクライアント側の固定値を使用したものであり、強固な暗号化ではありません。端末の物理的なセキュリティを確保してください。

## 4. 外部への通信

本拡張機能が外部と通信するのは以下の場合のみです。

**Google AI Studio API (`https://generativelanguage.googleapis.com/`)**
- ユーザーが BYOK (Bring Your Own Key) API キーを設定し、要約・予測・関連キーワード機能を実行した場合のみ
- API キーはユーザーの端末から Google のサーバーへ直接送信されます。開発者のサーバーを経由しません
- 送信内容: API キー・記事本文 (無料公開部分のみ)・プロンプト
- 送信先の Google のプライバシーポリシー: https://policies.google.com/privacy

**その他**
- 開発者サーバーへの通信: **なし**
- ライセンス認証のサーバー照会: **なし** (端末内で完結)
- アクセス解析・トラッキング: **なし**

## 5. 第三者提供

収集した情報を第三者に提供・販売することは一切ありません。

## 6. クッキー・トラッキング

本拡張機能はクッキーを使用せず、ユーザーの行動をトラッキングしません。

## 7. Chrome Sync

テンプレートのお気に入り情報は `chrome.storage.sync` に保存され、Chrome アカウントでログインしている場合は他のデバイスと同期されます。これは Google の Chrome Sync の仕組みを使用しており、Google のプライバシーポリシーが適用されます。

## 8. 有料記事の扱い

本拡張機能は note.com の有料記事の有料部分には一切アクセスしません。抽出対象は無料公開部分のみです。
